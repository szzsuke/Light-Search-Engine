# ⚡ Light Search Engine

A lightweight search engine — built as a learning project to understand how search engines like Google actually work under the hood. It searches the full web using the **Bing API**, with **DuckDuckGo** used to power its knowledge panel.

**🌐 LIVE LINK:** https://szzsuke.github.io/Light-Search-Engine/

---

## What it does

Light Search Engine is an independent alternative to relying on a big provider. It pulls together:

- **Full web search results**, powered by the Bing API
- **Domain collapsing**, so duplicate results from the same site are grouped together
- **Predictive autocomplete** as you type
- **A knowledge panel** for quick facts about a topic (like Google's info box), powered by DuckDuckGo
- **Safe search** toggle to switch between filtered and unfiltered results
- A **3D animated background** (built with Three.js) and ambient background music, just for fun

It's meant to be simple to read, run, and extend — a good starting point if you want to learn how search, autocomplete, and knowledge panels work.
